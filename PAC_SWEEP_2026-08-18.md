## Manual PAC 2024 pass — instructions

PAC 2024 is Windows GUI-only; there is no machine-readable output. For each
sample above:

1. Open PAC 2024 → File → Open → pick the sample PDF from
   `C:\projects\pdf\apex\edit-dotnet-pac\`.
2. Wait for the summary. Record fatals / errors / warnings in the table.
3. If any *Structure Elements* failure, click through and paste the specific
   rule name + count in Notes.
4. Cross-check against the corresponding source PDF baseline in
   `C:\projects\pdf\apex\SamplePDFs-ExtracredJSON\<sample>\<sample>.pdf` —
   any regression vs source is a bug for us.

## What the iText verifier does / does not cover

iText's `PdfUA1Checker` is a fast smoke — it catches catalog metadata,
structure-tree, and font-embedding regressions programmatically. It does
**not** replace PAC 2024, which additionally covers:

- Visual regression against source (unchanged regions unchanged)
- Heading hierarchy semantics
- Colour contrast
- Alternative-description text quality
- Reading-order sanity (beyond struct-tree correctness)

Any PDF that passes iText verify but fails PAC 2024 is a real bug in our
PDF/UA coverage worth filing.
